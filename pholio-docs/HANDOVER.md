## 3. Cara kerja website

Website ini menggunakan halaman statis. Website tidak memiliki CMS, backend, database pesanan, akun pembeli, atau keranjang multi-item kecuali ada perubahan scope tertulis.

Produk ditampilkan dari data katalog yang disiapkan di repository. Pembeli diarahkan ke halaman checkout eksternal per produk atau ke WhatsApp. Website tidak menyimpan status pembayaran atau menangani refund.

### Mengubah produk atau foto

- Untuk perubahan konten, kirim daftar perubahan dan file preview yang diperlukan melalui saluran yang disepakati.
- Perubahan produk dilakukan pada data JSON, lalu website perlu di-build dan di-deploy ulang.
- Jangan mengunggah foto master ke folder publik atau repository.
- Penambahan produk/foto di luar kuota dan perubahan desain dapat dikenai biaya terpisah.
- Update mandiri melalui dashboard CMS tidak tersedia pada paket dasar.
